## Projects

### 🏥 [MediCore HMS](https://github.com/vivektyagi05/MediCore-HMS)

Hospital management platform for doctor, patient, and appointment workflows.

Centralizes admin/doctor/patient operations behind one role-aware system instead of siloed manual records. Layered Express backend (controllers → services → middleware) over MongoDB, React + Vite frontend, JWT auth with RBAC.

**Tech Stack:**  
`React` `Vite` `Tailwind CSS` `Express.js` `MongoDB` `JWT`

**Status:** v0.1.0-alpha · Active Development · MIT License

---

### 🤖 [AI Generator](https://github.com/vivektyagi05/Ai_Generator)

Django application serving LLaMA 3.1 responses through the GROQ API.

Wraps a raw LLM API into a deployable application with OTP email verification (Resend API), session authentication, chat history, and cloud deployment.

**Tech Stack:**  
`Python` `Django` `GROQ API` `Resend API`

**Deployment:** https://ai-generator-k573.onrender.com

**Status:** Live Demo · MIT License

---

### 🎓 [SmartAttend](https://github.com/vivektyagi05/SmartAttend-AI)

Academic administration platform for teachers, students, classes, and timetables.

Replaces manual academic record-keeping with a centralized role-based system. Includes a Docker-based architecture with a dedicated AI attendance microservice planned for future implementation.

**Tech Stack:**  
`React` `Node.js` `Express.js` `MongoDB` `Docker` `JWT`

**Status:** v1.0.0-beta · MIT License
