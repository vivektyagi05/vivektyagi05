## Featured Projects

### 🏥 [MediCore HMS](https://github.com/vivektyagi05/MediCore-HMS)
A modular hospital management platform handling doctors, patients, appointments, and admin workflows through a layered backend.

- **Problem solved:** Centralizes hospital operations (patient records, doctor scheduling, appointment lifecycle) behind a single role-aware system instead of siloed manual processes.
- **Architecture:** Layered Express backend (controllers → services → middleware) over MongoDB, with a React + Vite frontend consuming a REST API secured by JWT and role-based access control.
- **Stack:** `React` `Vite` `Tailwind CSS` `Node.js` `Express` `MongoDB` `JWT`
- **Status:** Active development · MIT Licensed

### 🤖 [AI Story / Response Generator](https://github.com/vivektyagi05/Ai_Generator)
A deployed Django web app that generates AI responses using the GROQ API (LLaMA 3.1), with full account and session handling.

- **Problem solved:** Wraps a fast LLM inference API in a production-shaped web app — auth, verification, and history — rather than a bare API demo.
- **Architecture:** Django backend calling the GROQ API, with OTP-based email verification via the Resend API and session-based authentication; deployed on Render with Gunicorn.
- **Stack:** `Python` `Django` `GROQ API (LLaMA 3.1)` `Resend API`
- **Live demo:** [ai-generator-k573.onrender.com](https://ai-generator-k573.onrender.com)

### 🎓 [SmartAttend](https://github.com/vivektyagi05/SmartAttend-AI)
An academic administration platform for managing teachers, students, classes, and timetables, with an AI attendance service planned on top.

- **Problem solved:** Replaces manual academic administration (teacher/student records, class assignment, scheduling) with a centralized, role-based system built for institutions.
- **Architecture:** React + Vite frontend, Express/Node.js REST API, MongoDB, containerized with Docker Compose; a dedicated AI microservice is scaffolded for future face-recognition attendance.
- **Stack:** `React` `Node.js` `Express` `MongoDB` `Docker` `JWT`
- **Status:** v1.0.0-beta · MIT Licensed

## Engineering Principles

- Ship a stable core before adding scope — features are marked *stable*, *architecture-ready*, or *planned*, never overstated.
- Keep business logic in service layers, not controllers.
- Secure by default: JWT auth and role-based access control on every multi-user project.
- Document decisions, not just code — every project ships with its own architecture notes.
